# WanderLust

WanderLust is a full-stack Airbnb-inspired web application built using Node.js, Express, MongoDB, and EJS.

## Features

- View all listings
- View a single listing
- Create a new listing
- Edit an existing listing
- Delete a listing
- RESTful routing
- Method Override support

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML
- CSS

## Installation

```bash
git clone https://github.com/Abhishek5003/WanderLust.git
cd WanderLust
npm install
npm start
```

Visit:

```
http://localhost:8080/listings
```
